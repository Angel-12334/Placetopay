# DISPERSIÓN DE UN COMERCIO

- [Regresar](./../README.md)

La dispersión permite dividir el valor de un pago entre diferentes destinatarios.
Es útil cuando una sola compra debe distribuir su dinero entre diferentes participantes o beneficiarios.

Por ejemplo, en un marketplace un cliente podría realizar una compra de $100.000 que contiene productos de 
dos vendedores diferentes. El pago se realiza como una sola operación para el cliente, pero mediante la
dispersión el valor puede distribuirse entre los destinatarios correspondientes.

Ejemplo:

- Vendedor A: $60.000
- Vendedor B: $40.000
- Total de la compra: $100.000

De esta manera, la dispersión facilita la distribución de los fondos de una transacción entre diferentes 
destinos.
