# DIFERENCIA ENTRE SUSCRIPCIÓN Y RECURRENCIA

- [Regresar](./../README.md)

Aunque ambos conceptos permiten realizar cobros futuros, suscripción y recurrencia cumplen funciones 
diferentes.

## Suscripción

La suscripción permite almacenar de forma segura el medio de pago de un cliente mediante tokenización.
En lugar de guardar directamente los datos de la tarjeta, Placetopay genera un token que el comercio puede 
almacenar y utilizar posteriormente para realizar nuevos cobros.
La suscripción por sí sola no significa que se realizará un cobro automáticamente cada cierto tiempo.

## Recurrencia

La recurrencia permite programar cobros automáticos y periódicos sobre un medio de pago.
El comercio puede definir características como la periodicidad, el intervalo y la fecha del próximo pago.
Por ejemplo, puede utilizarse para cobrar automáticamente una mensualidad cada mes.

## Diferencia principal

La suscripción permite guardar de manera segura un medio de pago para utilizarlo posteriormente, mientras 
que la recurrencia establece cobros automáticos que se ejecutan periódicamente.

Un medio de pago tokenizado mediante una suscripción puede ser utilizado posteriormente para realizar 
diferentes cobros.
