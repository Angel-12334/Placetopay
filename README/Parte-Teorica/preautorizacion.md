# PREAUTORIZACIÓN

- [Regresar](./../README.md)

Una preautorización permite reservar una cantidad de dinero en la tarjeta de un cliente sin realizar el 
cobro inmediatamente. Este proceso es útil para comercios que al inicio no conocen con exactitud cuánto será 
el valor final del servicio.

El proceso puede dividirse en tres etapas:

1. **Check-in:** se reserva un monto en la tarjeta del cliente, pero todavía no se realiza el cobro.
2. **Reautorización:** permite ajustar el monto reservado si el valor del servicio cambia.
3. **Checkout:** se finaliza el proceso cobrando el valor correspondiente o liberando el dinero reservado.

## Ejemplo

Un hotel puede realizar una preautorización de $500.000 al momento en que un huésped realiza el check-in.
El dinero no se cobra inmediatamente, sino que queda reservado.
Si al finalizar la estadía el valor total del servicio es de $420.000, el hotel puede realizar el checkout 
por ese valor y finalizar la operación. De esta manera, el comercio tiene mayor seguridad de que existen 
fondos disponibles antes de prestar el servicio.
